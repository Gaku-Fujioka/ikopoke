## Goal・採用範囲

- 黒い輪郭のオレンジのポケットに「い」を描くアイコン。フォント依存のないSVGパスを原稿とし、共通ヘッダー/認証画面と、192/512px・Apple用180px・faviconへ展開する。全体ホーム右側の大きな装飾と、そのための余白はユーザー指摘で削除する。
- 白・黒・オレンジの基調、グループ→次の楽しみ→地図→近況の順、個人用グループ色、主要な操作名は維持。グループカードの下部、グループの候補欄、全体の候補一覧にポケット/縫い目の形を添える。
- 「見つけた行き先を、ポケットへ」など、候補をためる箇所に表現を限定する。「行きたい」「訪問記録」等の操作名や保存先の意味は置き換えない。
- Web App Manifest、ホーム画面追加の案内、対応ブラウザでの明示的な追加ボタン、iPhone/iPad向けの案内、standaloneとセーフエリア、接続/更新の案内を実装。
- Service Workerはアプリの通常ナビをネットワークへ流し、通信失敗時だけ公開の静的接続案内を返す。キャッシュは`/offline.html`だけ。認証・写真・会計・RSC・POST・外部APIをキャッシュ/再送しない。
- 更新は自動で再読み込みせず、入力を保存してから押すボタンで適用。初回の制御開始や別タブの更新で入力中の画面を強制再読込しない。
- Manifest/SW/接続案内だけをAuth proxyの対象から外す。既存の認証・RLS・Storage制御を緩めない。

## 対象外・仮定

公開・DNS/外部Auth設定・追加契約・新しい依存・DB変更は含めない。Push通知、私的データのオフライン閲覧/保存、バックグラウンド送信は別検討。
ホーム画面追加はブラウザ/OSによって挙動が異なる。公開HTTPSとiOS/Android実機の確認前にインストール成功と報告しない。
SVGによる作図は今回の試作判断。正式な見た目はユーザーが確認する。既存README・スターター32件の削除・未追跡pnpmファイルと`work/`を保全する。

## ユーザー確認リスト

- [ ] `/brand/ikopoke.svg`：ポケットの形・オレンジ・「い」の読みやすさ。faviconとホーム画面の縮小表示も確認。
- [ ] `/auth/login`・`/auth/sign-up`と共通ヘッダー：ポケットのマークが馴染む。文字やボタンが隠れない。
- [ ] `/app`：グループカード下部のポケット/縫い目とホーム上部の文言。右側の大きな装飾はなく、元の並び順が変わらない。
- [ ] `/app/items`：ポケット型の案内と文言。検索・絞り込み・候補へのリンクが使える。
- [ ] グループホーム：候補欄の縫い目と形、行きたい追加の案内。グループ色が区別でき、スマホ幅でも操作できる。
- [ ] ホームまたはプロフィール→「いこポケをホーム画面へ」：自分のブラウザに合う追加手順・ボタン。
- [ ] 公開HTTPSでのiPhone/Android追加と、アイコンからの起動・ログイン復帰・縦横表示・上下の余白。
- [ ] 通信切断の案内と、接続復帰後の再読込。記録や写真をオフラインで保存済みと誤表示しない。
- [ ] 更新通知が出ても入力中の画面は自動で切り替わらない。入力を保存してから明示的に更新できる。
