## Goal・要件・採用範囲

F-04/05、N-02/03/04/06、D-008/012。ユーザーが名前・スポット／やりたいこと・メモでの共有保存を承認した。
名前は空白不可・100文字以内、メモは任意・2,000文字以内。Unicode code pointで数え、前後空白を除く。
所属者がグループ内で追加・一覧・詳細を開け、再読込で再取得する。登録者はセッションから記録する。
1操作のrequest UUIDを保持し、同じ内容の再送を冪等にする。別の内容や登録者によるUUID再利用は拒否する。
DBへの直接読み取りも所属で制限し、直接のINSERT/UPDATE/DELETEと匿名RPC実行を許可しない。
