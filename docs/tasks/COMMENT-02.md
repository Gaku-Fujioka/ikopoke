## Goal・範囲・Done

所属グループの候補でコメントを投稿・閲覧する。独立チャット、コメント編集・削除、プロフィール名、通知・即時同期は対象外。
小さい仮定として本文はメモと同じ2,000 Unicode文字まで・空白のみ不可とし、日時は日本時間と明記する。
投稿者は「あなた／グループのメンバー」の区別までで、他人のメール・Auth UUID・名前を返さない。名前表示は未実装と明示する。

## 実装と検証

- `item_comments`と2つの限定RPCをmigrationへ記録する。FKはRESTRICTで、退会・削除の規則は確定しない。
- SELECT列をid・item_id・body・created_atへ限定し、RLSで所属候補だけ公開。直接書込とcreated_by参照を許可しない。
- 作成は所属・候補のグループ一致・本人ID・入力を検証し、request UUIDの同一再送で重複させない。別内容・別人・別候補でのUUID再利用は拒否する。
- 取得RPCは所属を検証して20件・新しい順・安定したID順と全件数を返す。空ページも全件数を保持する。
- Server Actionは検証・認証後に保存し、成功時だけ再取得と次のrequest UUID発行を行う。失敗時は本文とUUIDを維持する。
- 古いコメントページで投稿した場合は最新ページへ戻り、候補一覧の検索条件・ページは保つ。
- SQLの権限・文字数・改ざん・再送・ページ・所属削除、Actionの失敗時保護・生データ非公開、取得異常を検証する。
- 実DB適用・実ユーザー投稿・モバイル/キーボード・複数ユーザー確認は未実施。CI・統合結果は[まとめ](SHARED-TOOLS-01.md)。
