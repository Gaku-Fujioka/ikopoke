## Goal・採用範囲

F-11、N-01/02/03/04/06/10、D-031。友達・恋人・家族との日常を、写真とひとことでその場でも帰宅後でも残す。

- 訪問ページと自由ページへのひとこと、最後の寄せ書き。本人だけ編集/削除し、名前は現在の所属に応じて表示する。
- 既存の訪問の間へ自由ページを挿入。名前・本文は全メンバー編集可。訪問の章名も本専用に変更し、元の候補/訪問先名は保持する。
- 自由ページにも非公開写真を追加。既存の10枚/10MB・送信予約/完了/取消・退出/削除の制御を再利用。
- 終了前にも同じ一冊を開ける入口。終了/取消/再終了で一冊と追記を保全し、全員の入力を完成条件にしない。
- 自由ページは先頭/選んだページの後へ追加。既存訪問は従来の時系列。自由ページは基準の訪問とともに移動する。
