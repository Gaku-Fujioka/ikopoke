状態：実装・自己検証・開発DB適用済み。作成日：2026-10-18。担当：本Agent単独。CIと統合結果は本branchのPRを正本とする。

## Goal / 採用内容

F-02/04/05/06/07/08/10/11、N-01/02/03/04/07/09/10。
ユーザーが画面案「地図でひろがる」の改訂版を承認し実装を指示した。
スマホ中心の温かく遊び心のある共通枠、実データの4タブと共通＋を提供する。
ホームは全所属グループを集約し、グループカード→次の楽しみ→地図枠→近況の順。
グループ内ホームにも同じ構成を使い、名前変更・招待・メンバーは設定へ移す。
近況は4件以下なら2列、5件以上なら小さな3列。各カードから実詳細へ進める。

## Scope / Constraints

`app/app/`共通枠・ホーム・全グループ一覧・追加入口、`components/layout/`と新規home部品、
`lib/home/`、近況RPCのmigration・型・関連テスト・CI、判断と進捗文書。
既存の保存/RLS/競合検知/検索/写真/アルバム機能を再利用する。
地図API・外部検索・位置情報・通知配信・課金・PWA・削除権限は対象外。
候補に座標がないため地図枠は未接続と明示し、実際の候補検索と手入力を利用可能にする。
近況は既存の現在データから生成する。反応は現在の値と更新日時、取り消した反応は消える。
履歴監査やリアルタイム通知ではない。表示名は現在も同じグループのメンバーの場合のみ公開。
README、旧スターター削除、pnpm関連とwork/の既存変更をステージしない。

## 結果

- ホーム/4タブを全グループの実データへ接続。グループ内ナビも同じ対象を保持する。候補追加は独立画面、訪問追加は保存先/候補の選択から既存フォームへ進む。設定の招待/無効化も移動先を再取得する。
- 近況は最大12枚をホームへ表示し、一覧は20件ずつkeysetで取得。現在の反応・作成記録のUIで、監査履歴/既読/配信/常時同期ではない。取得失敗は0件と表示しない。次の予定と近況を別のSuspense境界へ分け、保存Actionは要約の取得完了を待たず対象パスを無効化する。
- 全225件のNodeテスト、lint・型を含む本番build成功。追加18件で所属/匿名/元メンバーの表示名、反応の変更/取消、同時刻の安定したページ送り、検索の記号と復帰、実ナビの共有先とカード密度、ホームの読込境界、3モード計画の閲覧/訪問/開閉編集を確認した。テスト用の合成providerとPGliteであり、実ブラウザ/実Authの成功ではない。
- 開発用DBへ`shared_home_activity`を実version `20261018023733`で適用した。依存の存在と対象関数の不在、適用履歴・所有者postgres・STABLE/SECURITY DEFINER/空search_path・PUBLIC/anonの実行不可・authenticatedの実行可を確認。関数本体のMD5はローカルと一致。認証主体なしでの呼出しは28000で拒否。ユーザーデータ/認証情報は取得・表示していない。
- Advisorの追加は意図した[認証済みSECURITY DEFINER実行](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable)の警告のみ。所属確認付きの読取RPCのため維持。既存の匿名`rls_auto_enable`、漏えいパスワード保護、2件のFK索引不足/未使用索引は対象外。
- 固定レビュー対象：基準`0c28b12`から本branchのcommitまでの差分と新規ファイル。所属の再検証、RLS/列権限の維持、UI型への射影、更新後の再取得、URL条件/共有先保持、空/エラー、地図の未接続表示、既存変更の除外を自己レビュー。独立レビューはD-009に従い未実施。CI/mergeはPRを正本とし、ローカル成功と区別する。
