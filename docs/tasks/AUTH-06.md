# AUTH-06：外部メール送信とSupabase SMTP

作成・更新日：2026-10-17。状態：独自ドメイン未所有を確認、サービス選定中。F-01、N-04/05/07、D-011。本Agent単独。

## Goal・採用範囲

AUTH-05で確認した送信回数上限を受け、ユーザーが外部メール送信サービスの設定を選択した。
SupabaseのカスタムSMTPへ接続し、別アカウントの登録・確認メール受信・招待への復帰を検証する。

## 前提・未決定

- ユーザーは独自ドメインを持っていないと回答。サービスはまだ採用していない。
- Resendは候補。対応プラグインの検索結果は空だったため、設定は公式画面の手順をチャットで案内する。
- ResendのSMTPは認証済みの独自ドメインを要するため、そのままでは接続できない。ドメイン取得の費用条件または既存メールアカウントのSMTP利用を確認する。
- 現行の公式資料でSupabase連携・送信ドメイン・料金を確認する。送信枠、Supabase側の上限、初回送信の結果を別々に扱う。
- 有料申込・ドメイン購入はこのタスクの既存許可に含めない。秘密のSMTP認証情報はユーザーが設定画面へ直接入力し、チャットやアプリへ移さない。

## Done・検証

サービスと送信元の条件を確定し、DNS認証・SMTP接続・確認メール到着・ログインと招待復帰を確認する。
SMTP設定の変更と確認メールの送信は、ユーザー操作で実施状況を記録する。DB migrationやメール確認無効化は行わない。
