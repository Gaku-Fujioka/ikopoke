# VISIT-UX-01：写真と一緒に訪問を残し、思い出から振り返る

作成日：2026-10-21。状態：ローカル検証・自己レビュー済み。ユーザーの操作確認とマージ指示待ち。担当：本Agent単独。
branch：`feat/visit-memory-flow`。基準main：`0bd401f56d7b09e4491d5a80e837f2e217d0fe2f`。
対象：F-02/10/11、N-01/03/04/06、D-034。

## Goal・Done

- 候補・計画からの訪問作成時に、日付・メモ・個人評価と一緒に写真を選択し、プレビュー・取り外し・保存ができる。写真なしも可能。
- 写真の上限・形式はD-018を維持（10枚、各10MB、JPEG/PNG/WebP）。既存の非公開Storage・予約/完了検証・RLSを再利用する。
- 訪問本文を保存してから写真を直接Storageへ送る。部分失敗は本文保存済みと表示し、同じ訪問・写真IDで残りを再試行する。詳細へ進んで後から追加する入口も提供する。
- グループホームの上部に「全体ホームへ／すべてのグループを見る」を明示する。
- 全体・グループの思い出に「アルバム／訪問記録」と「訪問を記録」を表示する。全体の訪問記録は`/app/memories?view=visits`、グループは既存`/visits`を使う。
- 訪問は日付別の一覧にし、先頭写真・写真枚数・場所名・メモ・任意の時間を表示。全体ではグループ名も表示する。
- 20件ずつページ送りし、所属RLSで取得した当該ページの写真だけを一括取得する。写真読取失敗時も訪問本文と詳細リンクを保持する。

## 範囲・対象外

変更：訪問作成フォーム/Server Action/写真転送補助、一覧repository、訪問タイムライン、思い出共通ナビ、全体/グループの思い出と訪問一覧、グループホーム、CSS、関連テスト/CIと本タスク記録。
DB・外部設定・依存は変更しない。写真の圧縮/HEIC変換、訪問詳細全体の再設計、アルバム本体の変更、ホームの並び変更は含めない。
既存README変更・旧スターター32件の削除・未追跡pnpmファイルと`work/`は保全し、今回のcommitに含めない。

画面の構成・文言は依頼の範囲でのAgent実装判断。写真は送信開始後に選び直さず、再試行または詳細で未完了送信の確認/中断を行う。ブラウザを閉じた場合の未送信ファイル自体の保持は行わない。
