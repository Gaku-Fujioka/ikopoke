# CALENDAR-01：共有計画を日付から開く

作成日：2026-10-18。状態：main統合・ユーザーの基本操作確認済み。担当：本Agent単独。
branch：`feat/outing-calendar`、基準：`3af2790`。

## Goal・対象

F-08/09、N-02/03/04。D-014の順次実装指示と、PLAN-02で保存した単日の予定日を使い、月間表示・日付ごとの計画一覧・計画詳細への移動・日付を指定した作成入口を提供する。
既存の日付文字列をそのまま扱い、予定日をタイムゾーン変換しない。今月の初期表示は日本時間、週は日曜始まりとする小さい表示上の仮定。

## 範囲と制約

- 既存の認証・所属RLSと計画取得を再利用し、新しい外部API・依存・DB変更は加えない。
- 記念日、年次繰返し・閏日規則、タイムゾーンを伴う予約、外部カレンダー同期は対象外。Q-14全体の採用ではない。
- 既存のREADME変更・旧スターター削除・pnpmファイルを保持し、コミットに含めない。
- 変更対象は`lib/outings/calendar.ts`、カレンダーのServer Component、計画一覧・作成導線、関連テストと記録。

## Done・検証

- 月・年境界と閏日を含め、保存された日付に計画を表示できる。
- 月/日付の選択をURLに保持し、選択した日から開く作成フォームに日付が入る。
- 計画の日付変更はカレンダーへ再取得で反映する。取得失敗と予定0件を区別する。
- 関連Nodeテスト、lint・型検査・build、固定差分の自己レビュー、CIを確認する。
- 実アカウント・ブラウザ幅/キーボードは自動検証と区別し、必要な操作をチャットで案内する。

## 結果

- 月/日付ごとの表示、予定0件、前後月・今日・任意月の選択、日付を引き継ぐ作成とログイン復帰を実装した。保存Actionはカレンダーも再取得対象に含める。
- 閏日・年越し・日本時間の今日、同日に複数の計画、月外の予定の除外、未認証の復帰先・非所属の404・取得エラーと空表示の区別を6件で検証。合成providerによる実Server Componentの検証であり、実PostgRESTやブラウザ操作とは区別する。
- ローカル全181件のNodeテスト、lint、型検査、build成功。既存のNext設定とNodeモジュール形式の警告は今回変更していない。
- 固定する対象はこのbranchのコミット。自己レビューで認証前の取得防止、グループ境界、日付のUTC算術とタイムゾーン変換の非適用、URLの引継ぎ、取得失敗時の表示を確認した。独立レビューはD-009に従い未実施。CI・統合の結果は該当PRを正本とする。
