# ここいこ プロダクト仕様 v1.0

## 1. コンセプト

友人・恋人・家族などの少人数で「行きたい場所」「やりたいこと」を気軽に共有し、実際のおでかけ予定を作り、最終的に思い出として残す。

中心フロー：

`行きたい・やりたい → リアクション → 行くことを決める → おでかけ計画 → 実際に行く → 思い出`

## 2. 行きたい場所

メイン機能。保存対象はカフェ、レストラン、水族館、美術館、公園、観光地、温泉、ホテル等。

保持候補：

- 名前
- 写真
- 住所
- 緯度・経度
- メモ
- 優先度
- リスト
- URL
- 登録者
- 登録日時
- 外部Place ID

## 3. やりたいこと

具体的な場所が決まっていなくても登録可能。

例：陶芸する、花火を見る、ドライブする、ピクニックする。

後から具体的なスポットへつなげられる。

## 4. グループ

複数グループを作成可能。グループ内で以下を共有する。

- 行きたい場所
- やりたいこと
- リスト
- リアクション
- コメント
- おでかけ
- 記念日
- 思い出

MVPではグループメンバー全員が基本編集可能。

## 5. リスト

グループごとに自由なリストを作成。

例：ごはん、カフェ、東京、旅行、夏にやりたい。

将来は個人リストからグループへの共有も検討。

## 6. リアクション・コメント

リアクション：

- 行きたい
- あんまり

誰が反応したかを表示。

スポット・やりたいことごとに短いコメントを付けられる。独立したチャット機能はMVPでは作らない。

## 7. ホーム

候補コンテンツ：

- 次のおでかけ
- 2人/みんなが行きたい
- 最近追加された場所
- やりたいこと
- 近くの保存スポット

「次にどこへ行くか」を考えたくなる画面にする。

## 8. 行きたい一覧・地図

一覧では場所とやりたいことを閲覧・絞り込みできる。

地図では保存済みスポットをピン表示し、詳細へ移動できる。

## 9. おでかけ

複数スポットを1つのおでかけとしてまとめる。

作成経路：

- 行きたい場所から「計画へ」
- おでかけ一覧から新規作成
- カレンダーの日付から作成

### 計画モード

1. 時間指定：12:30 / 14:00等
2. 時間帯：午前 / 昼 / 午後 / 夜等
3. 時間なし：順番だけ

## 10. カレンダー・記念日

汎用カレンダーではなく、ここいこに関係する予定だけ扱う。

初期表示対象：

- おでかけ予定
- 記念日

記念日は毎年繰り返し設定可能。

## 11. おでかけ中

スポットごとに記録ボタンを用意。

- 写真
- メモ
- 感想
- 評価

を記録可能にする。

## 12. 思い出

おでかけ終了後、記録した写真・メモ・スポットを時系列でアルバム化。

Stitch案のような本・旅行雑誌風UIを目標にする。

編集候補：

- 表紙
- 写真
- メモ
- 表示写真

## 13. 行った場所

訪問済みでもリストから削除せず「行った！」状態を表示。
5段階評価を行った後に保存可能。

## 14. 通知（後半）

候補：

- 新しい場所が追加された
- リアクションされた
- 明日はおでかけ

初期実装では優先度を低めにする。

## 15. MVPで後回し

- 外部アプリ共有
- 高度な通知
- AI推薦
- AI自動プラン
- Google Calendar同期
- 高度な権限管理
- チャット
- SNS化

## 16. UI方針

- モバイルファースト
- 親しみやすい
- 温かい
- カップル専用感に寄せすぎない
- 写真を活用する
- 業務アプリ風にしない
- 情報過多にしない

現在のStitch案を最初の実装ベースとし、実際に触って改善する。
